# CSS

Este portfólio apresenta os conceitos básicos de CSS e sua importância na criação e estilização de páginas web.

## Objetivo

Aprender os conceitos básicos do CSS, utilizando:

- O que é CSS
- Para que serve
- Seletores
- Cores
- Fontes
- Tamanhos
- Margens
- Espaçamentos
- Bordas
- Classes e IDs

## Organização

- introducao/: explicação sobre o CSS
- conceitos/: conceitos básicos de estilização
- seletores/: exemplos de seletores
- estilos/: exemplos de cores, fontes e tamanhos
- atividades/: exercícios básicos de CSS

## Ferramentas utilizadas

- HTML
- CSS
