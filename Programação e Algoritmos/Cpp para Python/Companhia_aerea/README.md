Sistema de Companhia Aérea

Este projeto consiste em um sistema de gerenciamento de uma companhia aérea desenvolvido em Python, permitindo cadastrar passageiros, registrar voos, comprar e cancelar passagens.

Objetivo

Praticar lógica de programação e manipulação de dados utilizando:

- Variáveis e listas
- Funções
- Estruturas condicionais ("if" e "elif")
- Estruturas de repetição ("while" e "for")
- Entrada e saída de dados
- Validação de informações
- Manipulação de arquivos JSON
- Exportação de arquivos CSV
- Criação de backups
- Importação de bibliotecas ("json", "os", "csv" e "shutil")

Funcionalidades

- Cadastro e consulta de passageiros
- Cadastro e consulta de voos
- Compra de passagens
- Escolha de assentos
- Cálculo de taxa de bagagem extra
- Cancelamento de passagens
- Relatório administrativo
- Exportação de relatórios em CSV
- Criação de backups dos dados

Organização

- sistema.py: código principal do sistema
- companhia_aerea_dados.json: armazenamento dos dados
- relatorio_passagens.csv: relatório exportado
- backup_companhia_aerea.json: cópia de segurança dos dados

Tecnologias utilizadas

- Python
- JSON
- CSV
- Bibliotecas padrão do Python
