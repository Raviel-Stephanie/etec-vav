# ABRIL LARANJA

Este site apresenta informações básicas sobre o Abril Laranja, uma campanha de conscientização e prevenção contra a crueldade e os maus-tratos aos animais.

## Objetivo

Informar sobre a importância da proteção e do respeito aos animais, utilizando:

- HTML
- Títulos e textos
- Imagens
- Links
- Listas
- Parágrafos

## Organização

- introducao/: apresentação do Abril Laranja
- conscientizacao/: informações sobre maus-tratos
- protecao/: formas de ajudar e proteger os animais
- imagens/: imagens relacionadas à campanha

## Tecnologias utilizadas

- HTML
