002 — ABOUT THE PROJECT

DESCRIÇÃO DO TRABALHO

Este trabalho consiste no desenvolvimento de um site para a BRAINROT INC., uma agência de marketing digital com uma identidade visual moderna, criativa e provocativa.

O projeto apresenta a marca, seus serviços, seus valores e sua proposta de comunicação no ambiente digital. O objetivo é demonstrar como elementos visuais, organização de conteúdo e design podem contribuir para a construção da identidade de uma empresa.

O site foi desenvolvido utilizando HTML para estruturar as páginas, CSS para definir a aparência dos elementos e Bootstrap para auxiliar na organização do layout e na adaptação a diferentes tamanhos de tela.

O projeto é dividido em páginas independentes, todas conectadas a um único arquivo CSS, permitindo organizar os estilos e manter uma identidade visual consistente em todas as seções.
