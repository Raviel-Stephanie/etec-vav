# História do HTML

Este site apresenta, de forma simples, a história do HTML e sua importância para a criação de páginas na internet.

## Objetivo

Conhecer a história e os conceitos básicos do HTML, utilizando:

- Origem do HTML
- Primeiro site da história
- Criador do HTML
- Estrutura básica do HTML
- Tags
- Títulos
- Parágrafos
- Links

## Organização

- historia/: origem e evolução do HTML
- primeiro-site/: informações sobre o primeiro site da história
- estrutura/: estrutura básica de uma página HTML
- tags/: exemplos de tags básicas do HTML

## Tecnologias utilizadas

- HTML
