# ANALISTA DE DADOS

Este portfólio apresenta informações sobre a profissão de Analista de Dados, sua formação e possibilidades de carreira na área de tecnologia.

## Objetivo

Conhecer os principais aspectos da profissão de Analista de Dados, utilizando:

- Conceito da profissão
- Principais funções
- Curso e formação
- Ferramentas utilizadas
- Habilidades necessárias
- Mercado de trabalho
- Carreira e possibilidades de crescimento

## Organização

- profissao/: informações sobre a profissão de Analista de Dados
- curso/: cursos e conhecimentos necessários para a área
- ferramentas/: principais ferramentas utilizadas por analistas
- carreira/: possibilidades de carreira e crescimento profissional
- mercado/: informações sobre o mercado de trabalho
- habilidades/: principais habilidades técnicas e profissionais
