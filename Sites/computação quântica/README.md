# COMPUTAÇÃO QUÂNTICA

Este repositório apresenta conceitos, aplicações e estudos relacionados à Computação Quântica.

## Objetivo

Conhecer os principais conceitos da Computação Quântica, ultilizando:

- qubits
- superposição
- emaranhamento quãntico
- portas quânticas
- algoritmos quânticos
- aplicações da computação quântica

## Organização

- Introdução/: conceitos básicos sobre computação quântica
- Conceitos/: qubits, superposição e emaranhamento
- Algoritmos/: principais algoritmos quânticos
- aplicações/: exemplos de uso da computação quântica
- projetos/: atividades e experimentos realizados

## Tecnologias ultilizadas:
